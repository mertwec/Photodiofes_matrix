# Задача 4: предварительная калибровка на старте:
реализуем эксперимент А Нож-сканирование по границе квадранта.

сканирование состоит из 3х частей i:
1. фиксация положения - луч в центре 
2. фиксация крайнее правое 
3. фиксация крайнее левое.

пункты 2 и 3 неважно в каком порядке

при старте отобразить метку: сканирование i 
как только фиксируем верное положение i, меняем цвет точки на зеленый -- индикатор что мы достигли необходимого положения.
в терминале запрос на ввод положения системы.
в результате калибровки мы получаем три числа соответствующие положению всей системы. 
каждое число значение угла на поворотном столике: {"i0": 0.0, "i1": 2.0, "i2": -2.0}

эти числа записываем в json файл для последующей обработки.

# Задача 8: алгоритм обработки сигнала 

Описание: Оптический 4х квадрантный датчик размерами 14 мм. отраженный луч лазера частотой  cfg.LAMBDA_UM, попадает на датчик. 
Диаметр пятна 2-3 мм. уровень засветки каждого квадранта   S_VAL_MAX = 0-20 -- квадрант засвечен,  S_VAL_MIN = 3500 - квадрант не засвечен.

цель: определить углы отклонения от луча.

и является сигналом для смены направления, чтоб вернуть пятно в центр.
