# динамический расчет размера пятна в потоке:

получая данные в потоке main stream фиксируем первые пришедшие значения по COM-порту как max и min, по ним рассчитать 
первоначальный размер пятна,
каждый момент когда данных все больше, обновлять максимальное и минимальное значение и пересчитывать размер пятна, так 
проведя датчиком из стороны в сторону получим реальное пятно засветки на датчике в реальном времени.

привязываться к углам v_x, v_y нельзя!! - они считаются некорректно. алгоритм динамического расчет размера пятна требует пересмотра.
как начальные данные в config.py известно максимальное и минимальное значение каждого квадранта s:
S_VAL_MAX = 20
S_VAL_MIN = 3500

при максимальной засветке квадранта значение = S_VAL_MAX, при минимальном = S_VAL_MIN. 
зная предельные значения рассчитать размер пятна по соотношениям засветки s1..s2
