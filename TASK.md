# динамический расчет размера пятна в потоке:

получая данные в потоке main stream фиксируем первые пришедшие значения по COM-порту как max и min, по ним рассчитать 
первоначальный размер пятна,
каждый момент когда данных все больше, обновлять максимальное и минимальное значение и пересчитывать размер пятна, так 
проведя датчиком из стороны в сторону получим реальное пятно засветки на датчике в реальном времени.

сканирование состоит из 3х частей i:
1. фиксация положения - луч в центре 
2. фиксация крайнее правое
