Визуализация данных с фотодиодного датчика размерами 2х2 (в дальнейшем возможно 4х4)

## расположение фотодиодов:
```
    s1 | s4
-------|-------
    s2 | s3
```

### Data Log:

    s1 - значение фотодиода сектора 1
    s2 - значение фотодиода сектора 2
    s3 - значение фотодиода сектора 3
    s4 - значение фотодиода сектора 4

    v_x - расчитанный угол отклонения от оси Х
    v_y - расчитанный угол отклонения от оси У 

### значения фотодиодов в логе:
- 20 — максимальная засветка фотодиода
- ~3400 — минимальная засветка фотодиода

> **Важно (поправка №1):** углы `v_x/v_y` считаются устройством некорректно и
> **не используются** в расчётах — они только отображаются как справочная величина.

## Формирование пятна

Размер засвечиваемого пятна считается **покадрово** прямо из `s1..s4`, без свипа и
без привязки к `v_x/v_y`. Опираемся на известные предельные сырые значения квадранта
(`config.py`):

```python
S_VAL_MAX = 20     # raw при максимальной засветке квадранта → доля b = 1
S_VAL_MIN = 3500   # raw при минимальной  засветке квадранта → доля b = 0
```

**1. Абсолютная доля засветки каждого квадранта** (`b_i ∈ [0, 1]`):

```
b_i = clip( (S_VAL_MIN − raw_i) / (S_VAL_MIN − S_VAL_MAX), 0, 1 )
```

**2. Радиус пятна** по модели top-hat (равномерная интенсивность по площади пятна).
Засвеченная доля площади детектора `f = mean(b_i)` приравнивается к доле площади
круга пятна на дисплее `size × size`:

```
π·r² = f·size²   ⇒   r = size·√(f / π)
```

- считается на каждый кадр → в потоке пятно «дышит» при наведении датчика на свет;
- клампится до `0.95·size/2`, чтобы круг не вылезал за дисплей;
- `f = 0` (нет света) → круг не рисуется.

| Засветка квадрантов (raw)     | f      | r при size=200 |
|-------------------------------|--------|----------------|
| все 0  (полная)               | 1.00   | 95 px (кламп)  |
| все 3500 (нет света)          | 0.00   | — (нет круга)  |
| `putty.csv` (raw ≈ 1034…3423) | ≈ 0.46 | ≈ 65…81 px     |

Центр пятна — это уже вычисляемая точка направления (`x_norm/y_norm`), от размера
независимая. Реализация: `spot_radius_px` в `src/pipeline/get_single_point.py`,
подробный разбор — в `AI_ANSWER.md` (раздел «Поправка №1»).
